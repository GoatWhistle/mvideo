## Задача — р. 0–2, с. 2–3, 16

- Построить пайплайн, который из текстовой карточки товара извлекает обязательные характеристики,
  нормализует их и для каждого значения выдаёт уверенность [р. 0; с. 3, 16].
- Для каталога маркетплейса М.Видео: тысячи категорий × десятки атрибутов, новые товары и категории
  каждый день [р. 1; с. 4].
- Результат — набор (атрибут, значение, уверенность) по каждой карточке [р. 2; с. 3].
- Зачем: заполненный атрибут → товар в фильтрах → выше CTR и конверсия → рост GMV [р. 2; с. 2].

## Обязательные требования

| # | Требование | Источник | Как проверим |
|---|---|---|---|
| R1 | Вход — только текст: заголовок, описание, атрибуты продавца; изображения не используются | р. 3; с. 10, 16 | Пайплайн не читает фото; схема входа в коде |
| R2 | Извлечь обязательные поля: бренд, модель, ключевые характеристики категории. Смартфон: бренд, модель, объём памяти, диагональ, ёмкость батареи, цвет. Ноутбук: бренд, процессор, RAM, накопитель, диагональ, цвет | р. 6; с. 3, 17 | Per-attribute метрики по каждому полю |
| R3 | Каждое значение привести к каноническому виду («алый» = «красный» = «red») | р. 2, 3; с. 4, 16 | Тест нормализации + справочники значений |
| R4 | Каждое значение сопроводить уверенностью; порог отделяет надёжные от ручной проверки | р. 3; с. 3, 17 | Калибровка, кривая precision/coverage по порогу |
| R5 | Не выдумывать характеристики: при LLM — схема вывода, справочники допустимых значений, проверка, что значение есть в тексте, порог уверенности | р. 3; с. 11, 15 | Доля значений без опоры в тексте = 0; тест на «пустых» карточках |
| R6 | Учитывать стоимость: гибрид, дешёвые методы на типовых случаях, дорогие — только где нужно | р. 3; с. 12, 15 | Доля карточек, ушедших в LLM; стоимость на 1 млн карточек |
| R7 | Одинаково работать для всех категорий и продавцов, включая редкие и небольших | р. 3; с. 15 | Метрики в разрезе категорий и продавцов |
| R8 | Начать с базлайна на правилах и словарях, затем ML или LLM, показать, что даёт каждый шаг | р. 4; с. 7, 16 | Таблица абляции: правила → модель → гибрид |
| R9 | Качество — precision/recall/F1 отдельно по каждому атрибуту на размеченном эталоне, не общая accuracy | р. 5; с. 5, 16 | Скрипт оценки, таблица по атрибутам |
| R10 | Coverage — доля карточек, где атрибут заполнен | р. 5; с. 5 | До/после пайплайна |
| R11 | Качество с учётом трафика: атрибуты, по которым чаще фильтруют, весят больше | р. 5; с. 5 | Веса из `query_clicks` (**наше:** источник весов, Q5) |
| R12 | Оценка на gold-сете по категориям, включая редкие | р. 5; с. 5, 14 | Метрики по категориям; gold-сет — Q3 |
| R13 | На защите показать риски и меры снижения: галлюцинации LLM, стоимость на масштабе, слабая оценка на хвосте, падение на новых категориях | р. 5; с. 15 | Слайд рисков |
| R14 | Шесть артефактов: код/ноутбук, README, EDA, пайплайн, файл предсказаний, презентация; один репозиторий или архив; запуск по README | р. 4; с. 18 | Чек-лист [PLATFORM.md](PLATFORM.md) |

## Необязательные пункты и бонусы

| # | Пункт | Источник | Что даёт |
|---|---|---|---|
| B1 | Петля обратной связи: ошибки и low-confidence → ручная разметка → дообучение или обновление правил | р. 4; с. 13, 14 | «это будет плюсом» |
| O1 | Мэппинг на справочник атрибутов маркетплейса после нормализации | р. 4; с. 13 | так устроен рабочий каталог, не оценивается явно |
| O2 | Стратегия разметки: active learning, weak supervision, LLM-assisted разметка | с. 14 | не оценивается явно |
| O3 | Устойчивость к новым категориям (cold-start) | р. 2; с. 11, 12 | входит в риски R13 |

Критерии жюри и веса не опубликованы (Q1). Ориентир — «Метрики успеха» [р. 5; с. 5], дословно:

| Критерий | Вес | Что даст максимум | Где покажем |
|---|---|---|---|
| Precision, recall и F1 по каждому атрибуту | без весов | Таблица по каждому обязательному полю, включая редкие значения; рост от базлайна к гибриду | Презентация, файл метрик, ноутбук оценки |

| Качество с учётом трафика | без весов | Метрики, взвешенные по реальному трафику фильтров/запросов | Презентация, ноутбук оценки |
| Оценка на эталоне по категориям | без весов | Метрики по каждой категории на человеческом gold-сете, хвост отдельно | Презентация, ноутбук оценки |
| Риски и меры снижения | без весов | Четыре риска из р. 5, у каждого — мера и замер | Слайд рисков |
