# Экран автоматического заполнения

Один запуск: текст продавца → автоматическая категория → поля правил → фоновое решение спорных значений → JSON. Слева исходник и выделенная цитата, справа результат. На узком экране панели идут последовательно. Визуальная система сохраняет существующие нейтральные токены до выбора стиля пользователем.

Состояния: пустой ввод, обработка, предварительные поля, завершение, неоднозначная категория, ошибка с повтором, частичный результат при сбое модели. Неподтверждённые поля видимы отдельно от заполненных. Экспорт содержит оба списка раздельно. Повторный запуск сбрасывает старый результат; правки текста во время обработки запрещены. Цитаты используют позиции Unicode из ответа API.

Проверка: реальный API без ключа, конфликт цветов, память 12/256 GB, вес 500 г, неизвестная категория, сбой сети, длинный текст, клавиатура, 375/1440px, RU/EN и обе темы. Новых анимаций нет; используются готовые общие компоненты. SQLite сохраняет исправления. Для исключений доступны предложенные кандидаты, ограниченный
алиас и отмена; при отсутствии кандидата открывается форма значения и точной цитаты. Сохранение
автоматически повторяет извлечение. Нормальные поля не требуют подтверждения.
