# Проверка экрана заполнения, 2026-10-15

Объём: существующая нейтральная система, без выбранного Refero-стиля. Изменения в отдельной
ветке feat/automatic-catalog. Матрица: 375 и 1440 px, light/dark, RU/EN; десять снимков
результата, конфликта и формы алиаса в /private/tmp/mvideo-ui-evidence. Снимки открыты и проверены
с начала документа. Это временные локальные артефакты, воспроизводимые через Playwright.

- Сценарий: реальный API, цитата, экспорт, выбор неоднозначной категории, ошибка/повтор, блокировка
  повторного запуска, сохранение правки, перезагрузка, отмена, использование алиаса следующей карточкой.
- Согласованность: сохранены общие Card/Button/Textarea/Icon, токены и нейтральная типографика.
- Доступность: axe на пустом и заполненном экране в четырёх сочетаниях тем и языков, на заполненном
  также обе ширины. Полный verify прошёл: 36 правил, TypeScript, Biome, 290 тестов, build.
- Устойчивость: отдельно проверен текст 24 тыс. символов с длинным неразрывным фрагментом, emoji
  и иероглифами на 375/720 px с reduced-motion: горизонтального переполнения нет, экспорт доступен.
  Это проверка reflow, не полноценная проверка браузерного zoom 200%.
- Движение: новых анимаций нет, используются существующие primitives. Численный замер fps не делался.
- Детектор impeccable: [] после запуска через writable временный cache; первоначальный запуск
  не мог создать cache в домашнем каталоге.

Независимая проверка по контракту impeccable в отдельном worktree дала fix: у обычных значений
не хватало происхождения и статуса калибровки. Добавлен общий FieldProvenance с переводами,
без процентов эвристики. Повторная проверка десяти снимков: найденный пункт resolved, disposition
ship для проверенного исправления. Состояния model/human проверены по коду, не по этим снимкам.
Использован свежий общий reviewer с контрактом degraded/finish-reviewer, так как именованные
роли скилла не доступны в harness. PRODUCT/DESIGN содержат прежние шаблонные поля; новая брендовая
система не утверждалась, токены не менялись.
