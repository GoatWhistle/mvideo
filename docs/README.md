# Документация «Атрибуты товаров»

> «Атрибуты товаров» извлекают обязательные характеристики из текстовой карточки товара и приводят
> их к формату каталога, с уверенностью у каждого значения. Значение принимается только с опорой —
> цитатой из карточки или двойником из каталога; это закреплено тестом, а значения ниже порога уходят
> в очередь проверки. Здесь — как решение устроено, почему именно так, как проверено, где его
> границы и как его запустить.

**Начните здесь, если вы в жюри:** [маршрут для жюри](for-jury.md) — 5 шагов по стенду и где ответ
на каждую метрику успеха из ТЗ. Обзор продукта — [README проекта](../README.md).
