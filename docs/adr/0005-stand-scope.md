# Стенд — одна страница без авторизации, на настоящем пайплайне

Кейс не требует стенда, но P0-сценарий для жюри показывает каскад и петлю обратной связи вживую:
карточка → атрибуты с уверенностью, цитатой и источником → очередь проверки → правка → повторный
прогон. Стенд — одна страница на шаблонных frontend/backend, без авторизации, запускается через
`docker compose up` без платных ключей и вызывает тот же код пайплайна, что и офлайн-предсказания.
