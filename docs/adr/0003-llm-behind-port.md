# Decision-модель — Jev за портом `DecisionModel`, без ключа работают кандидаты и CatBoost

Выбор среди кандидатов делает decision-модель через существующий порт `DecisionModel` и адаптер
`SystemOneModel` (`POST /v1/systemone`): TypeSafe Jev по API; тот же контракт заявлен у `laya-serve`
и OpenJev. Локальные веса Laya/OpenJev не используем: сеть стенда ~110 КБ/с не позволяет скачать
гигабайты весов. Без ключа (`DECISION_MODEL=lexical`) пайплайн, стенд и отчёт работают на
кандидатах и CatBoost; числа офлайн-заглушки как качество продукта не публикуются. Claude Haiku —
запасной путь для новых категорий за портом `LanguageModel`, только по явному запуску. Ответы
кэшируются по хешу карточки; платные прогоны — на выборке, стоимость на 1 млн карточек
экстраполируется.

## Следствия

- Отчёт метрик показывает результат с decision-моделью и без неё.
- В README команда без ключа — основная, с ключом — дополнительная.
