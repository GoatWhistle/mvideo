# LLM — Claude Haiku за портом, без ключа пайплайн работает на дешёвых ступенях

Для хвоста и новых категорий используем Claude Haiku через structured output, за портом шаблона с
детерминированным фолбэком: без ключа API LLM-ступень пропускается, а пайплайн, стенд и отчёт
работают на справочниках, правилах и ранжировщике. Ответы кэшируются по хешу карточки. Платные
прогоны — только по явному запуску, на выборке; стоимость на 1 млн карточек экстраполируется.

## Следствия

- Отчёт метрик показывает результат и с LLM-ступенью, и без неё.
- В README команда без ключа — основная, команда с ключом — дополнительная.
