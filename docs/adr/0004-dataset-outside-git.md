# Датасет хранится вне git, проверяется по SHA-256

Архив организаторов весит 1,1 ГБ (2,5 ГБ в распакованном виде), а GitHub не принимает файлы больше
100 МБ; Git LFS на каждый клон съедает квоту трафика. Архив кладётся в `brief/sources/dataset.zip`,
распаковывается в `data/raw/`, производные таблицы — в `data/processed/`; все три пути в `.gitignore`.
Контрольная сумма архива записана в `brief/sources/README.md`, README объясняет, где взять архив.
