# ADR 0006: SQLite для исправлений и алиасов

Статус: принято пользователем 2026-10-15.

Однопроцессный демонстрационный стенд хранит конфигурацию каталога, исправления и подтверждённые
алиасы в SQLite. Пользователь выбрал SQLite для текущего стенда. Файл живёт в именованном томе
Compose; перезапуск процесса сохраняет данные. Нет отдельного сервера БД и ORM.

Репозитории выполняют SQL через aiosqlite внутри Unit of Work. Запись открывает BEGIN IMMEDIATE;
выход без commit откатывает изменения. Миграции выполняет dbmate, seed — отдельная команда через
сценарий. HTTP-запросы не создают таблицы. Сетевой вызов Jev не удерживает транзакцию.

Исправление привязано к хешу текста, категории и атрибуту. Подтверждённый алиас ограничен категорией,
атрибутом и брендом; значение не становится глобальным правилом. Отмена сохраняет историю и
отключает применение. Оценка baseline не читает хранилище исправлений.
