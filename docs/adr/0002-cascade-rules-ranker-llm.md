# Извлечение — каскад «справочники → правила → ранжировщик → LLM», значение принимается только с цитатой

Кейс требует нормализацию, уверенность, отсутствие выдуманных значений и экономию на масштабе
(раздел 3; с. 12, 15). Каскад: справочники канонических значений и алиасов из пар
«продавец ↔ `_search`»; правила (парсер «ключ: значение», regex единиц, словари брендов и цветов);
ранжировщик кандидатов CatBoost с isotonic-калибровкой; LLM только для обязательных атрибутов без
уверенного значения. Каждое значение несёт цитату из текста карточки и источник (`rule`, `model`,
`llm`). Ниже порога — очередь ручной проверки; правка человека пополняет справочник алиасов.

## Рассмотренные варианты

- **Fine-tune BERT/NER:** отклонено на хакатон — не окупается за сутки; следующий шаг в презентации.
- **LLM на каждую карточку:** отклонено — стоимость на масштабе каталога, риск галлюцинаций.

## Следствия

- Значение без найденной в тексте цитаты или числа отбрасывается на любой ступени.
- Выход LLM ограничен enum из справочника; новое значение вне справочника идёт в очередь, а не в каталог.
- Порог выбирается на валидации по правилу из плана валидации; абляция показывает вклад каждой ступени.
