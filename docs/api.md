# API

Базовый путь: `/api/v1`. Актуальная схема: `/openapi.json`, Swagger: `/docs`.
Авторизации в демонстрационном стенде нет.

## Проверка здоровья

`GET /api/v1/health` возвращает состояние доступности процесса.

## Автоматическое извлечение

`POST /api/v1/extract/stream`, `Content-Type: application/json`.

```json
{"text":"Смартфон Samsung Galaxy S26 12/256GB Black\nВес: 500 г"}
```

`text`: от 1 до 30 000 символов после обрезки крайних пробелов.
`category_id`: необязательный положительный идентификатор для уточнения категории.

Ответ `200`, `Content-Type: application/jsonl`: одна JSON-запись на строку.
Последовательность `category` → `rules` → `complete`. Если категория неоднозначна,
приходят `category` и `complete` с `category_id=null` и списком `categories` для выбора.

Каждое поле содержит `attribute`, `state`, `reason`, `value`, `quote`, `start`, `end`,
`source`, `score`, `score_kind`, `confidence`, `alternatives`, `correction_id`, `correction_version`,
`alias_brand`.
Статусы: `accepted`, `review`, `not_stated`, `unsupported`. Только `accepted` входит в
заполненные поля экспорта. Цитата равна `source_text[start:end]` в позиции Unicode code points.
`confidence=null` до обучения калибратора; `score` не является калиброванной уверенностью.

Событие содержит длительность `elapsed_ms`, число вызовов `model_calls`, доступную статистику
`model_usage`, признак повторного кэшированного ответа `cached`, код сбоя фонового этапа `warning`,
версию словаря `catalog_version` и `synthetic_catalog`.

Ошибка входа до начала потока: `422` с `code=validation_error`.
Сбой модели после правил завершает поток с сохранёнными полями и `warning`.
Если соединение оборвалось до `complete`, клиент показывает ошибку и повтор; экспорт недоступен.

[Подробности каскада и ограничения](automatic-catalog.md).

## Исправления

`POST /api/v1/feedback` принимает `request_id` (UUID), `text`, `category_id`, `attribute`,
`value`, `quote`, `start`, `end`, `learn_alias` (по умолчанию false). Позиции относятся к
нормализованному тексту последнего извлечения. Значение должно соответствовать поддержанному
полю и допустимой цитате; числовое значение дополнительно проверяется кандидатами извлечения.

Ответ содержит `id`, `version`, `revoked`, `learn_alias`. Точный повтор UUID возвращает ту же
запись. Другой payload для UUID, конфликт активной правки или несовместимый алиас дают 409;
недопустимое значение/цитата — 422. Клиент после сохранения повторяет `/extract/stream` автоматически.

`POST /api/v1/feedback/{id}/revoke` принимает `{"version": 1}`. Отмена сохраняет историческую
запись, повышает версию и отключает её применение. Повтор отмены идемпотентен; устаревшая версия
активной записи даёт 409. В композиции без хранилища оба маршрута возвращают 503.

## Совместимость с прежним стендом

Маршруты прежнего синхронного стенда сохранены: `/stand`, `/examples`, `/extract`, `/review`
и `/review/{item_id}`. Они используют STAND_PACK и временную очередь в памяти; не являются
потоковым SQLite-сценарием. Прежний экран доступен по `/manual`, основной автоматический — `/`.

### Синхронные методы

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/v1/stand` | Категории, обязательные атрибуты и порог из пакета |
| GET | `/api/v1/examples` | Примеры карточек из пакета |
| POST | `/api/v1/extract` | Извлечение с явно заданной категорией; поля `title`, `description`, `seller_params` |
| GET | `/api/v1/review` | Временная очередь; фильтр `status=pending|accepted|corrected` |
| POST | `/api/v1/review/{item_id}` | `{"action":"accept"}` или `{"action":"correct","value":"..."}` |

Исправления этого контракта исчезают при перезапуске. Его числовой `confidence` — историческая
эвристика (в том числе 0,97 после проверки), а не калиброванная вероятность. Для долговечных
исправлений используйте `/feedback` и потоковый сценарий.

## Ошибки

Форма: `{"code":"validation_error","message":"..."}`. Интерфейс переводит `code` через словарь;
`message` предназначен для диагностики. 404 означает отсутствующую запись, 409 — конфликт
состояния, 422 — недопустимый ввод, 503 — недоступное хранилище или отсутствующий `STAND_PACK`
для синхронного стенда. Типы фронтенда генерируются из OpenAPI.
