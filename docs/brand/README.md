# Знак и логотип

Исходники знака в SVG. Из них собираются favicon и иконки приложения, знак в презентации и картинки README в `docs/readme/`.

| Файл | Где используется | Требования |
|---|---|---|
| `wordmark-light.svg` | Интерфейс и материалы на светлом фоне | Текст переведён в кривые, `viewBox` без лишних полей, читается при ширине 280–420 px |
| `wordmark-dark.svg` | Интерфейс и материалы на тёмном фоне | Та же геометрия, цвета для тёмного фона |
| `symbol.svg` | Favicon, иконки приложения, знак в презентации и в картинках README | Читается при 16 px, один цвет допустим |

Цвета знака совпадают с токенами интерфейса из `frontend/src/shared/styles/tokens/`. Исходники и
варианты, которые не используются, здесь не хранятся.
