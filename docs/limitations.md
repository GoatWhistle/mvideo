# Ограничения

- По умолчанию стенд работает с демонстрационным словарём смартфонов и ноутбуков. Это не полный
  каталог М.Видео. Seed загружает JSON в SQLite; API явно сообщает версию каталога и synthetic-статус.
- Категория определяется по ключевым словам первой строки. Непонятный или составной товар требует
  выбора категории. End-to-end точность автоматической категории на датасете не измерена.
- Контекстные фильтры не гарантируют семантическую корректность каждой цитаты. Новые формулировки,
  сравнения нескольких товаров, аксессуары в одной фразе и неизвестные модели требуют проверки.
- Уверенность не калибрована. Баллы правил и сырые вероятности Jev различаются в API;
  калиброванное поле остаётся пустым. Целевой precision не заявляется как результат.
- Jev интегрирован за портом и проверен тестовыми реализациями. Платный живой прогон не проводился.
  Без ключа работают правила. Повторная проверка ограничена двумя вызовами и общим тайм-аутом.
- SQLite рассчитана на текущий стенд с одним писателем за раз. Алиасы действуют только для
  категории, бренда и атрибута; автоматическое предложение ограничено известными каноническими
  значениями. Для неизвестного выражения без кандидатов оператор вводит значение и цитату.
  История отмен хранится, отдельного экрана истории нет.
- CatBoost и isotonic реализованы в офлайн-эксперименте; повторное обучение после исправлений и полная абляция не выполнены. Новые метрики и аудит проверены на синтетических
  контрпримерах; реального повторного прогона без локальных parquet-файлов не было.
- Эталон `*_search` не проверен независимо человеком. Аудит семейных пересечений эвристический;
  исходный SKU benchmark сохраняется и не становится автоматически независимым по семействам.
- Кэш модели ограничен памятью процесса, не объединяет одновременные дубликаты и теряется при рестарте.

[Что реализовано и как проверять](automatic-catalog.md), [запуск](running.md).

## Согласование с main, 2026-10-15

После обновления main сохранены реализация CatBoost/isotonic, пакетный Jev, эксперимент twins
и их прежние отчёты. Утверждения выше о незавершённом обучении относятся к повторному прогону
после исправлений единиц и метрик v2: он не выполнен. Эти артефакты не подключены к новому
автоматическому экрану; калиброванная уверенность в нём по-прежнему отсутствует.
