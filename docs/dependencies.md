# Зависимости

> Компоненты, библиотеки и модели «Атрибутов товаров» с версиями и лицензиями. Версии — те, что
> закреплены в lock-файлах и образах. Открытое ПО — под разрешительными лицензиями (MIT, BSD,
> Apache-2.0); единственная внешняя модель, TypeSafe Jev, — платный сервис и необязательна.

**Читайте, если** вы проверяете лицензионную чистоту или собираете решение в своей среде ·
**Связано:** [архитектура](architecture.md) · [запуск](running.md)

## Какие модели и данные используются?

| Модель или набор | Версия, источник | Лицензия | Где используется | Изменялась ли |
|---|---|---|---|---|
| Датасет кейса М.Видео | `dataset.zip` от организаторов хакатона «Точка сборки», SHA-256 `28758293f1174b2f19adcf2c99a86a9b5d2094aa22f3bbc92538af7180b59043` | Условия организаторов; в репозитории не хранится | Обучение, справочники, оценка | Нет |
| Ранжировщик CatBoost | Обучается командой `uv run ranker` на train | Собственные веса | Выбор кандидата офлайн и на стенде | Обучен на эталоне train |
| TypeSafe Jev | `typesafe/jev-1.13` через OpenRouter, контракт `/v1/systemone` | Платный API, условия TypeSafe и OpenRouter | Офлайн-ступень `decide` для спорных слотов; на стенде не используется | Нет |

Атрибуция моделей не требуется.

## Как обновить таблицы?

```bash
cd backend && uv tree --depth 1
cd frontend && npm ls --depth=0
```

Лицензии библиотек фронтенда — `npx --yes license-checker --production --summary` из `frontend/`;
бэкенда — `uv run --with pip-licenses pip-licenses --from=mixed` из `backend/`.
