## Как обновить таблицы?

```bash
cd backend && uv tree --depth 1
cd frontend && npm ls --depth=0
```

Лицензии библиотек фронтенда — `npx --yes license-checker --production --summary` из `frontend/`;
бэкенда — `uv run --with pip-licenses pip-licenses --from=mixed` из `backend/`.
